# Система управління бібліотекою відеоігор

## Опис предметної області

Проєкт присвячений моделюванню системи управління бібліотекою відеоігор.

Система призначена для зберігання інформації про користувачів, відеоігри та їхні ігрові бібліотеки. Користувач може мати власну бібліотеку, додавати до неї ігри та переглядати інформацію про них.

Також система передбачає зберігання інформації про жанри ігор та відгуки користувачів.

## Мета проєкту

Створити ER-модель, яка описує основні сутності предметної області, їхні атрибути та зв'язки між ними.

## Інструменти

- Mermaid — для створення ER-діаграми.
- GitHub — для зберігання проєкту та контролю версій.
